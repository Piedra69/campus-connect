Campus Connect

Gestión de solicitudes universitarias, responsables, recursos institucionales y reportes.

Abrir aplicación con base de datosVer código en GitHub

Aplicación y almacenamiento

La aplicación utiliza un servidor y una base de datos Cloudflare D1. Incluye registro, edición y eliminación de solicitudes, asignación de responsables, cambios de estado y exportación CSV.

Esta página pública está alojada en GitHub Pages. La aplicación se abre en su alojamiento independiente y conserva su control de acceso; puede solicitar iniciar sesión.
